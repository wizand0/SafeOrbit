## Критерии готовности

Работа считается завершённой только если:
- [ ] `\.\gradlew.bat assembleDebug` проходит
- [ ] `\.\gradlew.bat assembleRelease` проходит
- [ ] unit-тесты проходят
- [ ] нет merge-conflict markers
- [ ] нет plaintext PIN/кодов/URL в логах
- [ ] Firebase Rules проверены и протестированы
- [ ] pairing и commands не дают несанкционированного доступа
- [ ] Room безопасно мигрирует данные при обновлении
- [ ] listeners, callbacks, scopes и workers корректно завершаются
- [ ] изменения оформлены атомарными коммитами
- [ ] подготовлен финальный отчет
